# Greko Espresso Bar

[Open the presentation on GitHub Pages](https://weburon7.github.io/greko-espresso-bar/)

A café website prototype for Model Town and Eastwood Village in Jalandhar. Menu prices, offers, bookings, membership and staff edits are demonstrations stored in the visitor’s browser session. Use fictional details during walkthroughs.

GitHub Pages publishes the repository root from the main branch. Each route has an index.html for direct links. See SOURCES.md for image and type credits.
